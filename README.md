# tw-invoice-checker-web

發票來對喔APP官方網站

## 簡介

**發票來對喔**是一款專為台灣民眾設計的發票對獎工具，支援國/台語語音播報，讓您快速完成對獎，不再錯過任何中獎機會！

### 主要特色

**🎯 簡單快速對獎**

- 只需輸入發票末三碼，立即知道是否中獎
- 自動檢查特別獎、特獎、頭獎及增頒六獎
- 中獎時會播放勝利音效，未中獎也有提示音效

**🔔 自動更新開獎號碼**

- 應用會自動同步最新開獎號碼
- 支援離線使用，開獎號碼會儲存在手機中
- 可隨時查看完整開獎號碼詳情

**🎵 多種語音選擇**

- 提供國語男聲、國語女聲、台語男聲、台語女聲四種鍵盤音效
- 可完全關閉音效，適合各種使用情境
- 每按下數字鍵都會發出對應數字的語音

**🌓 深色/淺色模式**

- 內建深色與淺色兩種介面主題
- 可依個人喜好或使用環境自由切換
- 降低夜間使用對眼睛的負擔

**⌨️ 貼心的鍵盤設計**

- 大字體數字鍵盤，方便快速輸入
- 支援鍵盤排列順序切換（正序/倒序）
- 按鍵觸控回饋，提供流暢的操作體驗

### 使用方式

1. 開啟應用後，會自動下載最新開獎號碼
2. 在大字顯示區看到當期對獎月份（例如：113年3-4月）
3. 使用數字鍵盤輸入發票末三碼
4. 輸入完畢後自動對獎，並顯示結果
5. 如果中獎，會告訴您獎項和金額，並提醒您需要核對完整號碼

## 供APP使用的資源

- public/winning-numbers.json: 開獎號碼
- public/privacy-policy.html: 隱私政策

### 更新開獎號碼資料

自動化腳本 (`scripts/update-winning-numbers.js`)，可從財政部稅務入口網抓取最新開獎號碼

#### 自動更新

透過 GitHub Actions 定時執行，若偵測到新期別會自動更新 `public/winning-numbers.json` 並推送到儲存庫

#### 手動更新

執行以下指令可手動觸發爬蟲：

```bash
pnpm update:winning-numbers
```
