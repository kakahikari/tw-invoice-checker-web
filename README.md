# tw-invoice-checker-web

發票來對喔APP官方網站

## 簡介

**發票來對喔**是一款專為長輩設計的台灣發票對獎 App，提供大字體介面與國語、台語語音播報，只需輸入末三碼即可快速對獎，操作簡單、看得清楚、聽得明白，適合全家人安心使用。

### 主要特色

**👵 長者友善設計**

- 大字體介面、清楚按鈕間距
- 操作流程簡單直覺，長輩第一次使用也能馬上上手

**🎯 快速對獎不費力**

- 只需輸入發票末三碼，即可快速比對
- 省時又省眼力
- 自動檢查特別獎、特獎、頭獎及增頒六獎

**🔔 自動更新開獎號碼**

- 開獎資料自動同步，不需手動更新
- 支援離線查詢，開獎號碼會儲存在手機中
- 可隨時查看完整開獎號碼詳情

**🎵 國語 / 台語語音播報**

- 提供國語男聲、女聲與台語語音
- 對獎結果清楚唸出來，不必盯著小字看
- 可完全關閉音效，適合各種使用情境

**⌨️ 大字體鍵盤好輸入**

- 數字鍵盤字體放大、按鍵間距舒適
- 手指不易誤觸，輸入更準確
- 支援鍵盤排列順序切換（正序/倒序）
- 按鍵觸控回饋，提供流暢的操作體驗

**🎊 中獎音效即時提醒**

- 中獎與未中獎都有清楚音效提示
- 即使沒看螢幕也能馬上知道結果

### 使用方式

1. 開啟應用後，會自動下載最新開獎號碼（第一次打開會自動更新，無需任何設定）
2. 在大字顯示區看到當期對獎月份（例如：113年3-4月）
3. 使用大字體數字鍵盤輸入發票末三碼（數字清楚好按，長輩也能輕鬆操作）
4. 輸入完畢後自動對獎，並顯示結果（結果會同步顯示並語音播報，不必擔心看錯或漏看）
5. 如果中獎，會告訴您獎項和金額，並提醒您需要核對完整號碼（輸入末三碼僅為快速篩選，中獎後請務必再次核對完整八位數發票號碼）

## 供APP使用的資源

- public/winning-numbers.json: 開獎號碼
- public/privacy-policy.html: 隱私政策

### 更新開獎號碼資料

自動化腳本 (`scripts/update-winning-numbers.js`)，可從財政部稅務入口網抓取最新開獎號碼

#### 自動更新

透過 GitHub Actions 定時執行，若偵測到新期別會自動更新 `public/winning-numbers.json` 並推送到儲存庫

#### 手動更新

執行以下指令可手動觸發爬蟲：

```bash
pnpm update:winning-numbers
```
